Learning Programming

Repositório dedicado aos meus estudos em programação, desenvolvimento de software e tecnologia.

O objetivo é registrar minha evolução, praticar conceitos fundamentais e desenvolver projetos práticos ao longo do aprendizado.

 Tecnologias em estudo

- C++
- C#
- Lua
- SQL
- Git e GitHub

 
Organização:

Os conteúdos serão organizados por linguagem e assunto, incluindo exercícios, pequenos projetos e anotações.

1. Objetivos

- Fortalecer a lógica de programação.
- Aprimorar conhecimentos em diferentes linguagens.
- Desenvolver aplicações práticas.
- Construir gradualmente um portfólio de projetos.

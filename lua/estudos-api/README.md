# Estudos de APIs e Integração de Linguagens

Este diretório reúne estudos e aprendizados sobre APIs, integração entre linguagens de programação, análise de código-fonte e testes de software.

O objetivo é compreender como diferentes tecnologias podem trabalhar juntas dentro de uma aplicação, além de desenvolver habilidades de análise e documentação técnica.

## Objetivos

- Compreender o funcionamento de APIs.
- Estudar a integração entre Lua e C++.
- Desenvolver habilidades de leitura e análise de código-fonte.
- Entender parâmetros, tipos de dados e valores de retorno.
- Praticar testes e validação de funcionalidades.
- Aprimorar a documentação técnica.

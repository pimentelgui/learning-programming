Estudos de APIs e Integração de Linguagens

Registro dos meus aprendizados sobre APIs, integração entre linguagens, análise de código-fonte e documentação técnica.

 Objetivos:

- Compreender como aplicações disponibilizam funcionalidades por meio de APIs.
- Estudar a integração entre Lua e C++.
- Praticar a análise de funções e seus comportamentos.
- Aprender sobre testes e documentação técnica.
